Use the public API origin, without a trailing slash.

Create a tenant key

Requires the administrator key. The new key is returned once; save it securely.

Grant scopes

The default set is read, increment, and history. Listing exposes the tenant’s counter inventory, so grant counter:list only when needed. Leaving every scope unchecked uses the default set.

Create a counter

Uses a tenant key with counter:create for this tenant.

Generated command

The selected tenant key needs permission to create counters.

Tenant and credential IDs are copied manually from each JSON response. Commands contain the API key you entered; avoid sharing them or saving them in shell history.
